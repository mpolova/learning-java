## Structure

- `01-Introduction to Java/`: basics, variables, strings, and arrays

- `02-Intermediate Java/`: methods, control flow, loops, and coding challenges

- `03-OOP/`: object-oriented programming, classes, inheritance, interfaces, and polymorphism

- `04-Data Types and Exceptions in Java/`
  - `01-Advanced Java Types/`: wrapper classes, null handling, and additional practice classes
  - `02-Collections Framework/`: `ArrayList`, `LinkedList`, autoboxing, `HashSet`, `ArrayBlockingQueue`, `HashMap`, and the `Collections` and `Arrays` utility classes
  - `03-Exception Handling/`: try/catch, finally, exception objects, runtime vs. checked exceptions, throwing and rethrowing exceptions, and logging

- `05-Input Output and Streams in Java/`: file I/O, iterators, streams, custom methods, date/time, and enums

- `06-Introduction to Testing in Java/`: testing fundamentals, JUnit, Mockito, testing dependencies, annotations, and additional testing techniques

- `07-Optimizing Code in Java/`
  - software performance fundamentals and algorithm efficiency
  - measuring execution time, CPU usage, and memory usage
  - JVM memory management, garbage collection, and JIT compilation
  - multithreading, parallel streams, `ExecutorService`, and `CompletableFuture`
  - caching strategies and LRU caches
  - lazy initialization and the Singleton pattern
