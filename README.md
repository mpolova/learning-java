## Structure

- `01-Introduction to Java/` — basics: variables, strings, arrays
- `02-Intermediate Java/` — methods, control flow, loops, coding challenges
- `03-OOP/` — object-oriented programming: classes, inheritance, interfaces, polymorphism
- `04-Data Types and Exceptions in Java/` — advanced types, collections, and exception handling
  - `01-Advanced Java Types/` — wrapper classes, null handling, and additional practice classes (`ExamineWrappers`, `NullWithWrappers`, `SavingsAccount`, `Rocket`, `Movie`, `Launch`)
  - `02-Collections Framework/` — `ArrayList`, `LinkedList`, autoboxing, `HashSet`, `ArrayBlockingQueue`, `HashMap`, and the `Collections`/`Arrays` utility classes
  - `03-Exception Handling/` — try/catch, finally, the `Exception` object, runtime vs. checked exceptions, throwing and rethrowing exceptions, and logging
